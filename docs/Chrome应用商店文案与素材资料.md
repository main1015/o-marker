## 四、开发者后台「隐私权 (Privacy practices)」填报内容（1:1 对照）

在开发者控制台的 **“隐私权规范”** 页面，表单各项请**直接复制下方对应内容填入**：

### 1. 单一用途 (Single Purpose)
- **单一用途说明\***：
  ```text
  本扩展程序专为网页书签与个人知识库管理设计。核心功能为捕获用户想要收藏的网页信息（标题、URL、网站图标），并通过用户自托管的 o-marker 服务端进行树状集合分类、多维标签归档与实时收藏状态同步，提供纯净高效的书签管理体验。
  ```

---

### 2. 需请求权限的理由 (Permissions Justifications)

- **需请求 tabs 的理由\***：
  ```text
  用于在后台监听标签页切换与页面加载完成事件（chrome.tabs.onActivated 与 onUpdated），自动读取当前活动网址并向用户自建的服务端探测该页面是否已收藏。若已收藏，则在浏览器工具栏图标上即时展示对勾徽标（Badge），让用户无需每次点击插件即可一眼获知当前网页的收藏状态。
  ```

- **需请求 activeTab 的理由\***：
  ```text
  当用户主动点击扩展图标打开保存弹窗时，利用 activeTab 临时获取当前活动页面的网页标题、URL 地址与网站图标，以便在弹窗表单中自动预填网页信息，实现一键无感保存。
  ```

- **需请求主机权限的理由\***：
  ```text
  o-marker 是一款支持私有化自托管的书签系统。插件需要向服务端发起 HTTP/HTTPS 请求以同步书签数据、集合目录及校验收藏状态。由于用户既可以使用默认的本地服务（http://localhost:*/*），也可以将服务端部署在私有云端并自定义 API 域名（https://*/*），因此需要匹配对应的主机权限以保障自托管网络通信正常进行。插件绝不会向用户服务端以外的第三方网站发起未授权请求。
  ```
